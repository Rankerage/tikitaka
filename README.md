# TikiTaka — AI가 먼저 톡톡

> **"AI talks first. You just tap ○ or ✕."**

TikiTaka is the world's first **NoStressAI** companion.  
No commands. No setup. No learning curve.  

AI starts every conversation with a card.  
You respond with one tap.

---

## 🎯 What TikiTaka Is

| ✅ Does | ❌ Does NOT |
|--------|-----------|
| 🃏 Talk to you first (card interface) | Require any setup |
| 🧠 Learn your preferences via ○/✕ | Ask you questions (no question words) |
| ▲ Take commands when you want | Coach calls or record audio |
| 📖 Remember what you told it | Run terminal commands |
| 🪜 Get better every day | Need API keys |

> **Install. Tap ○. That's it.**

---

## 🚀 Start in 10 Seconds

```
1. Install APK
2. AI talks first: "환영합니다. 시작할까요?" [✕] [○]
3. Done.
```

---

## 🃏 How It Works

```
AI:  "이 목소리, 마음에 드실 거예요."  [✕] [○]
You: tap ○
AI:  "다음에 다른 목소리도 들려드릴게요." (card flips)

AI:  "오늘 새로운 IT 용어 하나 가져왔어요." [✕] [○]
You: tap ○
AI:  "프롬프트 엔지니어링: AI에게 원하는 답을 얻기 위해 질문을 설계하는 기술."

▲ = Your turn to ask
```

---

## 🧘 NoStressAI Philosophy

- Zero question words. Only recommendations.
- Double-tap cards learn your confidence level.
- Leitner spacing — confirmed preferences stop being asked.
- One week to perfect.
