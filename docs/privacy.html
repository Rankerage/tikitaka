📜 개인정보처리방침

최종 업데이트: 2026년 7월 28일

1. 수집하는 정보

TikiTaka는 아무것도 수집하지 않습니다.

  • 계정 가입 없음
  • 이메일 수집 없음
  • 전화번호 수집 없음
  • 위치 정보 수집 없음

모든 데이터는 사용자의 기기 안에만 저장됩니다.

2. 마이크 사용

마이크는 음성 명령과 TTS를 위해서만 사용됩니다. 녹음 내용은 저장되지 않습니다.

3. AI 대화

AI와의 대화는 Cloudflare Worker 프록시를 통해 OpenRouter로 전달됩니다. 대화 내용은 저장되지 않습니다.

4. 제3자 제공

어떤 정보도 제3자와 공유하지 않습니다.
