🏥 Hygieia · 💰 Plutus · 🎯 Clio

🏥

Hygieia

그리스 건강의 여신. "눈이 안 보여요" 한 마디로 시작하는 문진. 현대의학 + 한의학. 3년 축적 = 개인 건강 DNA.

💰

Plutus

그리스 부의 신. 시황 + 펀더멘털 통합 분석. 미국·한국 종목. 질문 3개면 맞춤 리포트.

🎯

Clio

역사의 뮤즈. 당신의 성격·건강·적성을 종합하여 최적의 진로를 카드 한 장으로.

🃏 카드 하나로 모든 것

전문 앱 100개를 이기는 방법.
100개의 기능을 하나의 ○✕로 통일하는 것.

📚

영어·수학·상식

Knowledge Engine. 200+장 내장. FSRS로 평생 기억.

📰

실시간 뉴스

Feed Engine. BBC·연합뉴스 RSS. 매일 새로운 카드.

📝

메모·기억

Mneme Engine. "기억해줘" 한 마디로 평생 기록.

🏓

티키타카 사운드

카드 뒤집을 때 탁구공 소리. ○✕ 리듬이 곧 공부.

🔊

TTS 음성

모든 카드 읽어줌. 앞면=남성, 뒷면=여성. 1.25배속.
