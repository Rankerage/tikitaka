왜 TikiTaka인가

AI가 먼저 말을 겁니다

당신이 질문하지 않아도 됩니다. AI가 먼저 카드를 건네며 대화를 시작합니다.

그냥 ○ 아니면 ✕

텍스트 입력도, 명령어도, 설정도 없습니다. 두 개의 버튼만 누르면 끝입니다.

쓸수록 나를 닮아갑니다

FSRS 알고리즘이 당신의 학습 패턴을 기억하고, 한 달이면 완벽해집니다.

완전 무료

API 키도, 구독도, 결제도 없습니다. 설치하고 바로 시작하세요.

모든 과목을 OX로

영어, IT 용어, 신조어, 수학 — 모든 학습이 카드 한 장으로 이루어집니다.

오픈소스
